# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/)
como base. En resumen:

## Lo que esperamos

- Tratar a las demás personas con respeto, también cuando no se está de acuerdo.
- Criticar el trabajo, no a quien lo hizo. Explicar el porqué de una objeción.
- Aceptar la revisión con buena fe y aprender de ella.
- Recordar que aquí hay gente que no programa: las explicaciones claras son bienvenidas.

## Lo que no se tolera

- Insultos, acoso, discriminación o comentarios degradantes.
- Publicar datos privados de otra persona sin su permiso.
- Insistir tras un «no» o llenar un Issue de ruido para llamar la atención.

## Qué pasa si ocurre

El mantenedor puede editar o eliminar comentarios, cerrar Issues o PR y, si se repite,
bloquear a quien lo haga. Para avisar de una conducta, escribe a **soporte@nomanorte.com** con un
enlace al mensaje; se trata con discreción. Si es un problema de seguridad, usa
[SECURITY.md](SECURITY.md).

Este código se aplica en el repositorio, sus Issues, PR y cualquier espacio que lo represente.
