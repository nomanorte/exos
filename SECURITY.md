# Seguridad

Si descubres una vulnerabilidad o sospechas que se ha publicado un secreto o dato personal,
no abras un Issue ni un Pull Request público con detalles. Usa la opción **Report a
vulnerability** de la pestaña Security de GitHub cuando esté disponible. Si todavía no
está habilitada, contacta al mantenedor por un canal privado antes de compartir pruebas.

No envíes claves reales, datos de otras personas ni volcados completos. Describe el impacto
y los pasos mínimos para reproducirlo con datos ficticios. El mantenedor evaluará el
reporte y decidirá la corrección y comunicación de la versión afectada.
